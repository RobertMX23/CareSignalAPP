Contexto

CareSignal es un MVP operacional. A partir del análisis inicial (score 44% con 20 tokens), se implementaron 30 tokens nuevos subiendo el score a 74%. El único gap pendiente es dark mode (P3), que no es necesario para el demo actual pero se requeriría antes de un lanzamiento a producción. Los scores del 85–90% reflejan que los tokens existen pero no se han migrado todos los valores hardcoded en el CSS existente — eso es trabajo futuro de refactor.
